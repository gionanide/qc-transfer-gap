FOUR FIXED MODELS

train.py trains the 2D U-Net, and train_multi.py trains any of the four
architectures. model.py and model_zoo.py contain the MONAI constructors,
including the decoder dropout (p = 0.1). The training constants are in
config.py, and the constructor settings of each model are in configs/.

TRAINING
Set QC_DATA_ROOT to the local ACDC database folder and QC_TRAIN_OUTPUT to a new
output folder. No machine-specific path is compiled into the sources.

python training/train.py
python training/train_multi.py --arch segresnet
python training/train_multi.py --arch attnunet
python training/train_multi.py --arch swinunetr --amp

The development split is generated by the code from the local Info.cfg files
with seed 42 (80 training and 20 validation patients). QC_VAL_FRACTION sets
the validation fraction (default 0.20). No patient lists
are distributed. The final checkpoint of each run is used for evaluation; the
evaluated weights are identified by SHA256SUMS and are provided in the
v1.0-weights release.

INFERENCE
python training/infer.py --help

Provide the local native phase image (with --frame for a zero-based 4D frame),
the final checkpoint, the architecture, the patient ID and the phase. Patient
IDs exist only as runtime inputs and output records. CPU is the default; use
--device to request CUDA. The input is resampled to 1.25 mm in-plane, centre
cropped or padded to 256 by 256, and normalised per slice. Native predicted
masks use the hard-label inverse of geometry.py, with nearest-neighbour
interpolation and zero fill.

--mc runs twenty MC-dropout passes with a fixed per-phase CRC32 seed recipe.
--loop selects slice-major (default) or phase-batched processing, and
--batch-slices sets the batch size (0 processes a whole phase). Keep the same
order when individual MC passes are compared. Per-pass native RV and LV
volumes and processed-mask hashes are saved, and analysis.mc_spread pairs the
ED and ES passes.

--stored-mask and --stored-entropy check the computed entropy against a saved
processed mask and its stride-two entropy array (tolerance 1e-5). The check
stops if more than 0.1% of the phase voxels change. --save-masks writes masks
to the runtime output folder only.

FINAL-CHECKPOINT DICE (SUPPLEMENTARY TABLE S11)
python -m analysis.final_checkpoint_dice --development-root data/ACDC/database/training --weights weights --output outputs/final_checkpoint_dice.csv

This evaluates the final weights on CPU on the 80/20 development split and
reports the phase-mean 3D patient Dice per class. It does not train or select
checkpoints. --include-test-root adds the held-out test partition.
